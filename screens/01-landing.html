Design your own learning path

เลือกคอร์สเรียงลำดับเอง ตั้งเป้าหมาย แล้วค่อยๆ ทำทีละขั้น — ข้อมูลเก็บในเครื่อง ไม่ต้องสมัคร ไม่ต้องมีบัญชี

  • สร้าง path — ตั้งชื่อแล้วอธิบายเป้าหมาย
  • เลือกคอร์ส — เพิ่มจาก library เรียงตามลำดับที่ต้องการ
  • check off — ทำเสร็จแล้วกด mark progress เก็บ offline
  • รับ badge — ครบทุกคอร์ส = achievement unlocked

    เขียนเนื้อหา — text-based, markdown ล้วน ไม่มีวิดีโอ

    เปิด PR — community review แล้ว merge เข้า main
