Lesson 1 — Setup + Install

เตรียม project ด้วย React + Vite แล้วติดตั้ง Leaflet — ใช้เวลาไม่เกิน 5 นาที

Prerequisites

ก่อนเริ่ม ควรมีสิ่งเหล่านี้ติดตั้งอยู่ในเครื่อง:

  • Node.js v18 ขึ้นไป — ดาวน์โหลด
  • npm หรือ pnpm — ตัวใดตัวหนึ่ง
  • Text editor ที่ถนัด — VS Code แนะนำ
Note

คอร์สนี้ใช้ pnpm ในตัวอย่าง แต่ npm หรือ yarn ก็ใช้ได้เหมือนกัน — แค่เปลี่ยนคำสั่ง install

สร้าง Project ใหม่

เริ่มจากสร้าง React project ด้วย Vite:

terminal 
pnpm create vite map-explorer --template react
cd map-explorer
pnpm install

จากนั้นติดตั้ง Leaflet และ type definitions:

terminal 
pnpm add leaflet
pnpm add -D @types/leaflet

นำเข้า Leaflet CSS

Leaflet ต้องการ CSS สำหรับ render map — เพิ่มใน src/main.tsx:

src/main.tsx 
import 'leaflet/dist/leaflet.css'
import React from 'react'
import ReactDOM from 'react-dom/client'
import App from './App'

ReactDOM.createRoot(document.getElementById('root')!).render(
  <React.StrictMode>
    <App />
  </React.StrictMode>,
)
Common pitfall

ถ้าไม่ import Leaflet CSS — map จะ render แต่ marker และ control จะหายไปหมด ไม่มี error ด้วย — ตรวจสอบให้แน่ใจว่า import แล้ว

ตรวจสอบว่าทำงาน

รัน dev server แล้วเปิด browser:

terminal 
pnpm dev

ถ้าเห็นหน้า Vite default — พร้อมแล้ว ไป Lesson 2: Render a Map ต่อได้เลย
