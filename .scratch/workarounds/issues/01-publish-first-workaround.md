# 01: เปิดอ่าน Workaround เรื่องแรก

**What to build:** ผู้อ่านเปิดรายละเอียด Workaround เรื่องการสร้าง User และกำหนดสิทธิ์ Database ใน PostgreSQL ได้ในหน้าเอกสารแยก เนื้อหาเดิมยังเข้าถึงได้ผ่านลิงก์หัวข้อเก่าที่พาไปหน้าใหม่; ผู้เขียนมีรูปแบบสำหรับเพิ่ม Workaround เรื่องถัดไปโดยไม่ต้องคัดลอกเนื้อหาไว้ใน Cheatsheet

**Blocked by:** None (can start immediately)

**Status:** resolved

- [x] Workaround เรื่องแรกแสดงรายละเอียดเดิมครบ รวม code block และองค์ประกอบ MDX โดยเนื้อหาวิธีทำอยู่ในเอกสารเดียว ไม่ซ้ำกับ Cheatsheet
- [x] URL หัวข้อ PostgreSQL เดิมที่มี fragment ยังเลื่อนไปยังหัวข้อสั้น ๆ ที่ลิงก์ไปหน้ารายละเอียดใหม่
- [x] เอกสาร Workaround กำหนดชื่อ คำอธิบาย tag ที่ไม่ว่าง และวันเผยแพร่ครั้งแรก; เรื่องแรกใช้ tag PostgreSQL และวันที่ย้ายขึ้นหน้าใหม่
- [x] เนื้อหารายละเอียดเขียน MDX อิสระ ไม่บังคับโครงหัวข้อ และการแก้บทความไม่เปลี่ยนวันเผยแพร่โดยอัตโนมัติ
- [x] ข้อมูลบังคับที่ขาดหรือวันเผยแพร่ใช้ไม่ได้ทำให้ build แจ้งข้อผิดพลาดเฉพาะ Workaround โดยเอกสารประเภทอื่นยังทำงานตามเดิม
- [x] สร้างเว็บ static แล้วเปิดหน้ารายละเอียดและลิงก์เก่าจริงเพื่อยืนยันพฤติกรรม; ระบุวิธีเพิ่มเรื่องใหม่ในเอกสารสำหรับผู้เขียน
