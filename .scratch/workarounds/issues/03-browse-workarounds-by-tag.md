# 03: เรียกดูและค้นหา Workaround ตาม tag

**What to build:** ผู้เข้าชมกด tag บนการ์ดหรือในรายละเอียดเพื่อเปิดหน้าเฉพาะ tag ซึ่งแสดงเฉพาะ Workaround ของ tag นั้น และค้นหาในรายการย่อยได้ โดย Astro สร้างหน้า tag จากข้อมูลที่มีตอน build

**Blocked by:** 02 — ค้นหา Workaround จากหน้ารวม

**Status:** resolved

- [x] หนึ่ง Workaround ติดได้หลาย tag และทุก tag ที่ใช้มีหน้า static เฉพาะของตัวเองโดยไม่ต้องสร้างหน้าด้วยมือ
- [x] tag บนการ์ดหน้ารวมและหน้ารายละเอียดกดไปหน้า tag ที่ถูกต้องได้; ไม่มีลิงก์บังคับย้อนกลับไป Cheatsheet
- [x] หน้า tag แสดงเฉพาะเรื่องที่มี tag นั้น เรียงล่าสุดก่อน และค้นชื่อกับคำอธิบายได้เฉพาะในเรื่องเหล่านั้น พร้อมสถานะไม่พบผลลัพธ์
- [x] ชื่อ tag ที่ต่างกันแต่แปลงเป็น URL เดียวกันทำให้ build แจ้งข้อผิดพลาดแทนที่จะทับหน้าเงียบ ๆ; การเปลี่ยนชื่อ tag เปลี่ยน URL ตามชื่อ ไม่สร้าง alias
- [x] เปิดเว็บที่ build แล้วกด tag จากทั้งการ์ดและรายละเอียด ค้นภายในหน้า tag และยืนยันว่าเรื่องนอก tag ไม่ปรากฏ
