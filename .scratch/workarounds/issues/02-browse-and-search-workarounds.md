# 02: ค้นหา Workaround จากหน้ารวม

**What to build:** ผู้เข้าชมเข้า Workarounds จากเมนูหลัก เห็นการ์ดของทุกเรื่อง เรียงวันที่เผยแพร่ล่าสุดก่อน ค้นจากชื่อหรือคำอธิบายสั้น ๆ แล้วกดไปอ่านรายละเอียดได้ โดยหน้ารวมสร้างตอน build และการค้นหาทำใน browser

**Blocked by:** 01 — เปิดอ่าน Workaround เรื่องแรก

**Status:** resolved

- [x] เมนูหลักมีทางเข้าหน้ารวม Workarounds และหน้ารวมมี URL ของตนเองซึ่งสร้างเป็น static
- [x] การ์ดแต่ละเรื่องแสดงชื่อ คำอธิบาย และ tag พร้อมลิงก์รายละเอียดที่เปิดได้จริง; ใน ticket นี้ tag ยังไม่ต้องลิงก์ไปหน้าที่จะสร้างใน ticket 03
- [x] รายการเรียงวันเผยแพร่ครั้งแรกล่าสุดก่อน; กรณีวันที่เท่ากันมีลำดับรองที่คงที่และการแก้เนื้อหาไม่ทำให้การ์ดเปลี่ยนลำดับ
- [x] ค้นหาจากชื่อและคำอธิบายสั้น ๆ ได้ ไม่ค้นจากเนื้อหาเต็ม และแสดงสถานะไม่พบผลลัพธ์เมื่อไม่ตรงคำค้น
- [x] เพิ่ม Workaround ที่ metadata ถูกต้องแล้วหน้าใหม่ปรากฏในรายการเมื่อ build ใหม่โดยไม่ต้องแก้รายการด้วยมือ; ไม่ต้องใช้ API runtime
- [x] เปิดเว็บที่ build แล้วตรวจเมนู การค้นหาจากชื่อและคำอธิบาย ลำดับเมื่อมีหลายเรื่อง สถานะไม่พบ และการกดเข้ารายละเอียด
