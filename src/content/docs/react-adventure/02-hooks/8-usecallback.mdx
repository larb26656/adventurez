ทุกครั้งที่ component render ฟังก์ชันที่เขียนในตัวมันจะเป็นคนละตัวกับรอบที่แล้ว `useCallback` จำฟังก์ชันเดิมไว้ จนกว่าค่าใน dependency จะเปลี่ยน

การ์ดชาทำแบบนี้:

```tsx
  const addItem = useCartStore((state) => state.addItem)
  const handleAdd = useCallback(() => {
    addItem(product)
  }, [addItem, product])
```

`handleAdd` อ่าน `addItem` กับ `product` จึงใส่ทั้งคู่ใน dependency กดปุ่มแล้วเรียก `addItem(product)` ซึ่งไปเพิ่มจำนวนในตะกร้า ถ้าสินค้านั้นอยู่ในตะกร้าแล้ว store จะบวก `quantity` ไม่ได้เพิ่มแถวซ้ำ

ไม่ต้องห่อทุกฟังก์ชัน ห่อเมื่อส่งฟังก์ชันนั้นลงไปใน component ที่ถูก `memo` หรือเมื่อฟังก์ชันไปอยู่ใน dependency ของ Hook อื่น การ์ดนี้ห่อไว้ให้เห็นรูปแบบชัดๆ แม้ปุ่มจะรับ `onClick` ตรงๆ ก็ตาม
