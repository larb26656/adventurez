`useMemo` จำผลลัพธ์ของการคำนวณ แล้วคำนวณใหม่เมื่อค่าใน dependency เปลี่ยน

ตัวอย่างที่พังบ่อยคือใส่ dependency ที่สูตรไม่ได้อ่าน การบวกเลขล้านรอบด้านล่างไม่ได้ใช้ `count` แต่ใส่ `[count]` ทำให้ทุกครั้งที่กดเพิ่มตัวนับ ลูปวิ่งใหม่ทั้งที่คำตอบเดิม

```tsx
  // ตัวอย่างที่ห้ามทำ ผลลัพธ์ไม่ได้ขึ้นกับ count
  const result = useMemo(() => {
    let total = 0
    for (let i = 0; i < 1000000; i++) total += i
    return total
  }, [count])
```

ถ้าคำตอบไม่ขึ้นกับอะไรเลย dependency ควรเป็น `[]` และถ้างานไม่หนักก็ไม่ต้องห่อ `useMemo` เลย

## ของตัวอย่างฝึก

รายการที่มองเห็นขึ้นกับเมนูทั้งก้อนและปุ่มที่กด สูตรอ่านทั้ง `products` และ `filter` ดังนั้นสองตัวนี้ต้องอยู่ใน dependency `useTeaFilter` ในบท custom hook ใช้สูตรเดียวกัน

```tsx
  const visibleProducts = useMemo(
    () =>
      products.filter(
        (product) => filter === 'all' || product.temperature === filter,
      ),
    [products, filter],
  )
```

- กด "เย็น" แล้ว `filter` เป็น `'cold'` เหลือชาที่ `temperature === 'cold'`
- กด "ร้อน" เหลือ `'hot'`
- กด "ทั้งหมด" คืนทุกรายการ
