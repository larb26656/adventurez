- **useState** จำตัวกรองและค่าที่ต้องวาดบนจอ
- **useEffect** ทำงานหลัง render เช่น ติดคลาสธีม อย่า setState ตัวที่อยู่ใน dependency โดยไม่มีเงื่อนไขหยุด
- **useRef** ชี้ DOM โดยไม่ทำให้ render ใหม่ ตัวอย่างฝึกใช้โฟกัสชื่อผู้รับ
- **useMemo** จำผลคำนวณ dependency ต้องเป็นค่าที่สูตรอ่านจริง
- **useCallback** จำฟังก์ชัน เช่น `handleAdd`
- **custom hook** รวม Hook เป็น `useTeaFilter` และ `useCupCount`

> ไฟล์ประกอบ: [examples/react/basics](https://github.com/larb26656/adventurez/tree/main/examples/react/basics)
