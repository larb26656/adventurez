`useEffect` ทำงานหลัง React วาดจอเสร็จ ใช้กับงานข้างเคียง เช่น แตะ DOM, ตั้ง timer, หรือเขียน `localStorage`

```tsx
// ตัวอย่างรูปแบบ ไม่ใช่ไฟล์ในร้านชา
useEffect(() => {
  // ทำงานหลัง render
  return () => {
    // cleanup ก่อนทำงานรอบใหม่ หรือตอน component ถูกถอด
  }
}, [dependencies])
```

| dependency | เมื่อไหร่ทำงาน |
| --- | --- |
| ไม่ส่ง array | หลังทุกครั้งที่ render |
| `[]` | ครั้งเดียวหลัง mount |
| `[theme]` | หลัง mount และทุกครั้งที่ `theme` เปลี่ยน |

## ธีมของร้านชา

`ThemeProvider` จำ `'light' | 'dark'` ด้วย `useState` แล้วใช้ effect นี้แปะ class ที่ `<html>` เพื่อให้ Tailwind v4 เห็นคลาส `dark`

```tsx
  useEffect(() => {
    const root = document.documentElement
    root.classList.toggle('dark', theme === 'dark')
    localStorage.setItem('tea-shop-theme', theme)
  }, [theme])
```

dependency มีแค่ `theme` เพราะบรรทัดใน effect อ่านแค่ตัวนี้ เปิดร้านครั้งถัดไปจะอ่าน `tea-shop-theme` จาก `localStorage` มาก่อน ถ้ายังไม่เคยเลือกจะดู `prefers-color-scheme`

ไฟล์เต็มอยู่บท Context พาร์ต 4 เพราะเรื่องนี้คือการส่งธีมข้ามต้นไม้ component ไม่ใช่แค่ effect

## Cleanup

ถ้า effect ไปตั้ง `setInterval` หรือ `setTimeout` ต้องคืนฟังก์ชันเพื่อล้าง ไม่เช่นนั้น timer ยังยิงหลังผู้ใช้เปลี่ยนหน้า หน้าสั่งชามี timeout สั้นๆ ตอนส่งฟอร์ม แต่ตัวนั้นอยู่ในการกดปุ่ม ไม่ได้อยู่ใน effect จึงไม่ต้องล้างด้วย effect

<ChatMessage message="ถ้าใส่ state ลง dependency แล้วไป setState ตัวนั้นใน effect จะวนไม่จบ" avatarKey="blackCat" />

```tsx
// ตัวอย่างที่ห้ามทำ
useEffect(() => {
  setCount(count + 1)
}, [count])
```

`count` เปลี่ยน เลยรัน effect อีก แล้วก็เปลี่ยน `count` อีก ร้านชาไม่ทำแบบนี้ effect ของธีมเขียน `theme` ลง storage แต่ไม่ได้เรียก `setTheme` ข้างใน
