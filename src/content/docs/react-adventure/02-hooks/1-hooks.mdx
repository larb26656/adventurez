Hook คือฟังก์ชันที่ขึ้นต้นด้วย `use` ใช้ต่อ component เข้ากับความสามารถของ React เช่น จำค่า, ทำงานหลังวาดจอ, หรือชี้ไปที่ DOM

ถ้าไม่มี Hook, ฟังก์ชัน component ถูกเรียกใหม่ทุกครั้งที่ render ตัวแปรธรรมดาจะเริ่มนับหนึ่งใหม่ทุกครั้ง ปุ่มเพิ่มแก้วจะเด้งกลับไปที่ 0 ทันทีที่กด

```tsx
import { useState } from 'react'

export function HooksIntro() {
  const [count, setCount] = useState(0)

  return (
    <section>
      <h2>Hooks</h2>
      <p>ตัวแปรธรรมดาเริ่มใหม่ทุกครั้งที่ render useState จำจำนวนแก้วไว้</p>
      <p>จำนวนแก้ว: {count}</p>
      <button type="button" onClick={() => setCount((current) => current + 1)}>
        เพิ่มแก้ว
      </button>
    </section>
  )
}
```

## กฎสองข้อ

1. เรียก Hook ที่ระดับบนสุดของ component หรือ custom hook ห้ามเรียกใน `if`, ในลูป, หรือในฟังก์ชันที่ซ้อนอยู่ React จำ Hook ตามลำดับที่เรียก
2. เรียกได้จาก component หรือจากฟังก์ชันที่ชื่อขึ้นต้นด้วย `use` เท่านั้น ห้ามเรียกจากฟังก์ชันทั่วไปเช่น `formatPrice`

## ตัวอย่างฝึกใช้ตัวไหน

| Hook | ใช้ทำอะไร | ไฟล์ในตัวอย่างฝึก |
| --- | --- | --- |
| `useState` | จำปุ่มกรอง และจำนวนแก้ว | `UseStateExample.tsx`, `HooksIntro.tsx` |
| `useEffect` | ติด class `dark` ที่ `<html>` แล้วเก็บธีม | `UseEffectExample.tsx` |
| `useRef` | ชี้ input ชื่อผู้รับ เพื่อ focus ตอนเปิดตัวอย่าง | `UseRefExample.tsx` |
| `useMemo` | คำนวณรายการที่ผ่านตัวกรอง | `UseMemoExample.tsx` |
| `useCallback` | ฟังก์ชันกดเพิ่มลงตะกร้า | `UseCallbackExample.tsx` |
| custom hook | รวมตัวกรอง และจำนวนแก้ว | `CustomHookExample.tsx` |
