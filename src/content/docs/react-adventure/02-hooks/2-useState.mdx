`useState` จำค่าข้ามการ render เมื่อเรียกฟังก์ชันตั้งค่า React จะวาด component ใหม่

```tsx
  const [filter, setFilter] = useState<TeaFilter>('all')
```

- `filter` คือค่าปัจจุบัน อ่านได้อย่างเดียว
- `setFilter` ใช้เปลี่ยนค่า
- `'all'` คือค่าเริ่ม ซึ่งตรงกับปุ่ม "ทั้งหมด"

ปุ่มบนหน้าเมนูมีสามปุ่ม ค่าใน state เป็นภาษาอังกฤษ ส่วนป้ายบนปุ่มเป็นภาษาไทย:

| state | ปุ่ม |
| --- | --- |
| `all` | ทั้งหมด |
| `cold` | เย็น |
| `hot` | ร้อน |

กดปุ่มแล้วเรียก `setFilter(item.id)` รายการที่โชว์ถูกกรองจาก `filter` ในไฟล์เดียวกัน บท useMemo จะย้ายการกรองเข้า `useMemo`

## ห้ามเขียนทับ state

```tsx
// ตัวอย่างที่ห้ามทำ
filter = 'cold'
```

แบบนี้ React ไม่รู้ว่าต้องวาดใหม่ ให้เรียก `setFilter('cold')`

ถ้าค่าใหม่ขึ้นกับค่าเก่า ใช้รูปฟังก์ชัน เพื่อไม่ไปอ่านค่าที่ค้างใน closure:

```tsx
      <button type="button" onClick={() => setCount((current) => current + 1)}>
        เพิ่มแก้ว
      </button>
```

บท useEffect ใช้รูปนี้ตอนสลับธีม: `setTheme((prev) => (prev === 'light' ? 'dark' : 'light'))`

## ก้อน object

ถ้า state เป็น object ต้องก็อปของเดิมมาก่อนแล้วค่อยทับ field ที่เปลี่ยน ตะกร้าทำแบบนี้ใน Zustand ด้วยการ spread `...item` ตอนเพิ่มจำนวน ไม่ได้แก้ `item.quantity` ตรงๆ
