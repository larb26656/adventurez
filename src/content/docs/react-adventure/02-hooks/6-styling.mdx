การ์ดชาต้องมีระยะ, สีพื้น, และปุ่มที่กดได้ วิธีหนึ่งคือ CSS Modules: ไฟล์ `.module.css` ที่ class ไม่ชนกับ component อื่น

```css
/* ตัวอย่างฝึก ร้านชาไม่ได้ใช้ไฟล์นี้ */
.card {
  border-radius: 1rem;
  padding: 1rem;
}
```

```tsx
// ตัวอย่างฝึก ร้านชาไม่ได้มีไฟล์นี้
import styles from './TeaCard.module.css'

function TeaCard() {
  return <article className={styles.card}>ชานมไต้หวัน</article>
}
```

อีกทางคือ inline style ผ่าน prop `style` มันติดกับค่าที่เปลี่ยนตาม state ได้ตรงๆ แต่อ่านยากเมื่อหน้าใหญ่ขึ้น ร้านชาไม่ใช้ทางนี้เป็นหลัก

พาร์ต 3 จะติดตั้ง Tailwind CSS 4 ผ่าน Vite plugin แล้วเขียน utility class บน element เช่น `rounded-2xl`, `bg-amber-800`, `grid-cols-4` ไม่มี `tailwind.config.js` และไม่มี `@tailwind base` แบบเวอร์ชัน 3
