การ์ดชาต้องมีระยะ, สีพื้น, และปุ่มที่กดได้ วิธีหนึ่งคือ CSS Modules: ไฟล์ `.module.css` ที่ class ไม่ชนกับ component อื่น

```css
.card {
  border-radius: 1rem;
  padding: 1rem;
  background: #fef3c7;
}
```

```tsx
import styles from './TeaCard.module.css'

export function TeaCard() {
  return <article className={styles.card}>ชานมไต้หวัน</article>
}
```

อีกทางคือ inline style ผ่าน prop `style` มันติดกับค่าที่เปลี่ยนตาม state ได้ตรงๆ แต่อ่านยากเมื่อหน้าใหญ่ขึ้น ตัวอย่างฝึกไม่ใช้ทางนี้เป็นหลัก

พาร์ต 3 ของร้านชาจะติดตั้ง Tailwind CSS 4 ผ่าน Vite plugin แล้วเขียน utility class บน element เช่น `rounded-2xl`, `bg-amber-800`, `grid-cols-4` ไม่มี `tailwind.config.js` และไม่มี `@tailwind base` แบบเวอร์ชัน 3 อย่าติดตั้ง Tailwind ลงในโปรเจกต์ `react-basics`
