## Part 2: Hooks — เพิ่มพลังให้ Components

เรียนรู้ React Hooks ที่จำเป็น — จัดการ state, side effects, และสร้าง Custom Hooks ของตัวเอง

สิ่งที่จะได้เรียนรู้:
- **useState** — จัดการ state ภายใน component
- **useEffect** — จัดการ side effects
- **useRef** — อ้างถึง DOM elements
- **useMemo** — optimize performance ด้วย memoization
- **Custom Hooks** — สร้าง hook ของตัวเอง
