## Part 2: Hooks

หน้าร้านต้องจำว่ากำลังกรองชาเย็นหรือร้อน, จำธีม, โฟกัสช่องชื่อตอนสั่ง, และไม่คำนวณรายการที่มองเห็นใหม่ทั้งก้อนถ้าตัวกรองไม่เปลี่ยน Hook คือฟังก์ชันที่ให้ component จำค่าและทำงานหลัง render

สิ่งที่จะได้เรียนรู้:

- **useState** เก็บตัวกรองทั้งหมด / เย็น / ร้อน
- **useEffect** ใส่ class `dark` และจำธีม
- **useRef** โฟกัสช่องชื่อผู้รับ
- **useMemo** กรองเมนูเฉพาะตอนข้อมูลที่เกี่ยวกับการกรองเปลี่ยน
- **useCallback** คงฟังก์ชันเพิ่มลงตะกร้า
- **custom hook** `useTeaFilter` กับ `useCupCount`

ตัวอย่างที่รันได้ของพาร์ตนี้: [examples/react/basics](https://github.com/larb26656/adventurez/tree/main/examples/react/basics) ร้านชาเอาแนวเดียวกันไปใส่ใน `useCartCount` ตอนพาร์ต 4
