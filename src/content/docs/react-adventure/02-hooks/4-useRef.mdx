`useRef` เก็บกล่องที่เปลี่ยนค่าได้โดยไม่ทำให้ component render ใหม่ ใช้ชี้ DOM หรือเก็บ id ของ timer

ตัวอย่างฝึกโฟกัสช่อง "ชื่อผู้รับ" ตอนเปิดตัวอย่าง ผู้ใช้ได้พิมพ์เลย

```tsx
  const nameInputRef = useRef<HTMLInputElement>(null)
```

```tsx
  useEffect(() => {
    nameInputRef.current?.focus()
  }, [])
```

`current` เริ่มเป็น `null` หลัง React แปะ input จริงแล้วจะชี้ไปที่ element เครื่องหมาย `?.` กันกรณีที่ยังไม่มี node

ปุ่ม "นับใน ref" บวก `clicks.current` โดยไม่เรียก `setState` เลขนั้นเลยไม่วาดบนจอ หน้าสั่งชาของร้านชาในพาร์ต 5 ใช้ ref ตัวเดียวกันเพื่อโฟกัส และส่ง ref ร่วมกับ React Hook Form เพราะ `register('name')` อยากได้ ref ของมันเองด้วย

## ต่างจาก useState

| | useState | useRef |
| --- | --- | --- |
| เปลี่ยนค่าแล้ว | render ใหม่ | ไม่ render |
| เหมาะกับ | ตัวกรอง, จำนวนแก้ว, ชื่อที่โชว์บนจอ | ชี้ DOM, ค่าที่จอไม่ต้องวาดตาม |

อย่าเอา `useRef` ไปเก็บจำนวนในตะกร้า ตัวเลขบนแถบนำทางจะไม่อัปเดต เพราะ React ไม่ได้ถูกบอกให้วาดใหม่
