## 🛠 Tech Stack

```
React + Vite        → Development environment
TypeScript          → Type safety
TanStack Router     → Type-safe routing
React Hook Form     → Form management
Zod                 → Validation
Tailwind CSS        → Styling
Framer Motion       → Animations
Zustand             → State management
TanStack Query      → Data fetching (bonus)
Vercel              → Deployment
```

## 📈 Project Evolution

```
Step 1: Counter          → เรียน useState, props
Step 2: Mock E-commerce  → เห็น props drilling pain
Step 3: Context/Zustand  → แก้ pain ด้วย state management
Step 4: Styling          → Tailwind + animations
Step 5: Routing          → หลายหน้า
Step 6: Forms            → validation
Step 7: Real API         → data fetching patterns
Step 8: Deploy           → Vercel
```
