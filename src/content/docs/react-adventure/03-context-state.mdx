## 2. Props Drilling: ปัญหาที่เจอ

### Scenario: เพิ่ม Cart Badge

สมมติเราต้องการให้ navbar แสดงจำนวนสินค้าในตะกร้า:

```
App
 └── Navbar (ต้องรู้ cart count)
      └── CartBadge
```

แต่ Navbar ไม่ได้ใช้ cart count โดยตรง — มันแค่ส่งต่อไปให้ CartBadge

```tsx
// ปัญหา: ต้อง drill props ผ่าน component ที่ไม่ได้ใช้
function App() {
  const [cartCount, setCartCount] = useState(0) // cart state อยู่ที่นี่

  return <Navbar cartCount={cartCount} onAddCart={() => setCartCount(c => c + 1)} />
}

function Navbar({ cartCount, onAddCart }: { cartCount: number; onAddCart: () => void }) {
  // Navbar ไม่ได้ใช้ cartCount โดยตรง แค่ส่งต่อ
  return (
    <nav>
      <Logo />
      <CartBadge count={cartCount} /> {/* ส่งต่อ */}
    </nav>
  )
}

function CartBadge({ count }: { count: number }) {
  return <span className="badge">{count}</span>
}
```

## 3. Context API: แก้ Props Drilling

### Context คืออะไร?

Context คือ **global state** ที่ accessible จากทุก component โดยไม่ต้อง drill props

### สร้าง ThemeContext (Light/Dark Mode)

```tsx
// src/contexts/ThemeContext.tsx
import { createContext, useContext, useState, type ReactNode } from 'react'

type Theme = 'light' | 'dark'

interface ThemeContextType {
  theme: Theme
  toggleTheme: () => void
}

const ThemeContext = createContext<ThemeContextType | null>(null)

export function ThemeProvider({ children }: { children: ReactNode }) {
  const [theme, setTheme] = useState<Theme>('light')

  function toggleTheme() {
    setTheme(t => t === 'light' ? 'dark' : 'light')
  }

  return (
    <ThemeContext.Provider value={{ theme, toggleTheme }}>
      {children}
    </ThemeContext.Provider>
  )
}

export function useTheme() {
  const context = useContext(ThemeContext)
  if (!context) {
    throw new Error('useTheme must be used within ThemeProvider')
  }
  return context
}
```

### สร้าง CartContext

```tsx
// src/contexts/CartContext.tsx
import { createContext, useContext, useState, type ReactNode } from 'react'
import type { Product } from '../data/products'

interface CartItem extends Product {
  quantity: number
}

interface CartContextType {
  items: CartItem[]
  addItem: (product: Product) => void
  removeItem: (id: string) => void
  clearCart: () => void
  totalItems: number
  totalPrice: number
}

const CartContext = createContext<CartContextType | null>(null)

export function CartProvider({ children }: { children: ReactNode }) {
  const [items, setItems] = useState<CartItem[]>([])

  function addItem(product: Product) {
    setItems(current => {
      const existing = current.find(item => item.id === product.id)
      if (existing) {
        return current.map(item =>
          item.id === product.id
            ? { ...item, quantity: item.quantity + 1 }
            : item
        )
      }
      return [...current, { ...product, quantity: 1 }]
    })
  }

  function removeItem(id: string) {
    setItems(current => current.filter(item => item.id !== id))
  }

  function clearCart() {
    setItems([])
  }

  const totalItems = items.reduce((sum, item) => sum + item.quantity, 0)
  const totalPrice = items.reduce((sum, item) => sum + item.price * item.quantity, 0)

  return (
    <CartContext.Provider value={{ items, addItem, removeItem, clearCart, totalItems, totalPrice }}>
      {children}
    </CartContext.Provider>
  )
}

export function useCart() {
  const context = useContext(CartContext)
  if (!context) {
    throw new Error('useCart must be used within CartProvider')
  }
  return context
}
```

### เปรียบเทียบ: ก่อน vs หลัง Context

| ก่อน (Props Drilling) | หลัง (Context) |
|----------------------|----------------|
| `<App cartCount={...}>` | `<CartProvider><App /></CartProvider>` |
| `<Navbar cartCount={...}>` | `const { totalItems } = useCart()` |
| `<CartBadge count={...}>` | `const { totalItems } = useCart()` |
| ต้อง drill ผ่านทุก component | เรียกใช้ตรงๆ ได้เลย |

## 4. ปัญหาของ Context + ทางออก: Zustand

### Context ยังมีปัญหา

แม้ Context แก้ props drilling ได้ แต่ยังมีข้อเสีย:

1. **Boilerplate** — ต้องสร้าง Context + Provider + hook ทุกครั้ง
2. **Verbose** — ต้องเขียน logic หลายตัวในไฟล์เดียว
3. **Re-render** — Context เปลี่ยน → component ที่ subscribe เปลี่ยน re-render หมด

### Zustand คืออะไร?

Zustand เป็น **lightweight state management** library ที่ใช้ง่ายกว่า Context

### ติดตั้ง Zustand

```bash
npm install zustand
```

### สร้าง Cart Store ด้วย Zustand

```tsx
// src/stores/cartStore.ts
import { create } from 'zustand'
import type { Product } from '../data/products'

interface CartItem extends Product {
  quantity: number
}

interface CartStore {
  items: CartItem[]
  addItem: (product: Product) => void
  removeItem: (id: string) => void
  clearCart: () => void
}

export const useCartStore = create<CartStore>((set) => ({
  items: [],

  addItem: (product) => set((state) => {
    const existing = state.items.find(item => item.id === product.id)
    if (existing) {
      return {
        items: state.items.map(item =>
          item.id === product.id
            ? { ...item, quantity: item.quantity + 1 }
            : item
        )
      }
    }
    return { items: [...state.items, { ...product, quantity: 1 }] }
  }),

  removeItem: (id) => set((state) => ({
    items: state.items.filter(item => item.id !== id)
  })),

  clearCart: () => set({ items: [] })
}))
```

### ใช้ Cart Store

แทนที่ CartContext ด้วย Zustand store:

```tsx
// src/App.tsx
import { useCartStore } from './stores/cartStore'

function CartBadge() {
  const totalItems = useCartStore(state =>
    state.items.reduce((sum, item) => sum + item.quantity, 0)
  )
  return <span className="cart-badge">{totalItems}</span>
}

function ProductCard({ product }: { product: Product }) {
  const addItem = useCartStore(state => state.addItem)

  return (
    <div className="product-card">
      <span className="product-image">{product.image}</span>
      <h3>{product.name}</h3>
      <p className="product-price">฿{product.price.toLocaleString()}</p>
      <button onClick={() => addItem(product)}>เพิ่มลงตะกร้า</button>
    </div>
  )
}

function CartPage() {
  const { items, removeItem, clearCart } = useCartStore()

  return (
    <div>
      <h2>ตะกร้าสินค้า</h2>
      {items.length === 0 ? (
        <p>ยังไม่มีสินค้าในตะกร้า</p>
      ) : (
        <div>
          {items.map(item => (
            <div key={item.id} className="cart-item">
              <span>{item.image}</span>
              <span>{item.name}</span>
              <span>x{item.quantity}</span>
              <span>฿{(item.price * item.quantity).toLocaleString()}</span>
              <button onClick={() => removeItem(item.id)}>ลบ</button>
            </div>
          ))}
          <button onClick={clearCart}>ล้างตะกร้า</button>
        </div>
      )}
    </div>
  )
}
```

### เปรียบเทียบ: Context vs Zustand

| Context | Zustand |
|---------|--------|
| `createContext` + `useContext` | `create()` จาก zustand |
| ต้อง Provider wrapper | ไม่ต้อง wrap |
| Re-render ทุก subscriber | Select เฉพาะ state ที่ต้องการ |
| Boilerplate เยอะ | Simple |

## Recap

| Pattern | ใช้เมื่อ | ข้อดี | ข้อเสีย |
|---------|---------|-----|---------|
| **Props Drilling** | App ง่ายๆ, component ตื้น | เข้าใจง่าย | ยุ่งยากเมื่อลึก |
| **Context API** | Theme, auth, global settings | Global access | Boilerplate, re-render issues |
| **Zustand** | Complex state (cart, etc.) | Simple, performant | Library dependency |
