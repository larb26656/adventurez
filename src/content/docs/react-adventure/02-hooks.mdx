## 1. useState: State พื้นฐาน

### State คืออะไร?

State คือ **ข้อมูลที่เปลี่ยนแปลงได้** และเมื่อเปลี่ยน → UI อัพเดท

### วิธีใช้ useState

```tsx
import { useState } from 'react'

function Counter() {
  const [count, setCount] = useState(0)

  return (
    <div>
      <p>ค่าปัจจุบัน: {count}</p>
      <button onClick={() => setCount(count + 1)}>+1</button>
    </div>
  )
}
```

**คำอธิบาย:**
- `useState(0)` — สร้าง state ชื่อ `count` เริ่มต้นที่ `0`
- `count` — ค่าปัจจุบันของ state
- `setCount` — function สำหรับเปลี่ยนค่า

### Workshop: ทำให้ Counter ทำงาน

แก้ `src/App.tsx`:

```tsx
import { useState } from 'react'

function App() {
  const [count, setCount] = useState(0)

  return (
    <div>
      <h1>Counter App</h1>
      <p>ค่าปัจจุบัน: {count}</p>
      <button onClick={() => setCount(count + 1)}>+</button>
      <button onClick={() => setCount(count - 1)}>-</button>
    </div>
  )
}

export default App
```

ลองกดปุ่ม + หรือ - ดูว่าค่าเปลี่ยนไหม

## 2. Functional Update

### ปัญหา: Stale State

ถ้า update state หลายครั้งใน function เดียว:

```tsx
const [count, setCount] = useState(0)

function increment() {
  setCount(count + 1) // count = 0
  setCount(count + 1) // count ยังเป็น 0 อยู่!
  setCount(count + 1) // count ยังเป็น 0 อยู่!
}
// Result: count = 1 (ไม่ใช่ 3)
```

### วิธีแก้: Functional Update

```tsx
function increment() {
  setCount(c => c + 1) // ใช้ function ที่รับค่าปัจจุบัน
  setCount(c => c + 1)
  setCount(c => c + 1)
}
// Result: count = 3 ✓
```

:::tip ใช้ functional update เมื่อ:
- Update state หลายครั้งใน function เดียว
- Update state โดยอ้างอิงจากค่าปัจจุบัน
:::

## 3. useEffect: Side Effects

### useEffect คืออะไร?

useEffect ใช้สำหรับ **ทำงานที่ไม่เกี่ยวกับ UI** เช่น:
- Fetch data
- เรียก API
- Set up subscriptions
- Update document title

### รูปแบบพื้นฐาน

```tsx
useEffect(() => {
  // code ที่จะรัน
}, [dependencies])
```

### Case 1: Run ทุกครั้ง render

```tsx
useEffect(() => {
  console.log('รันทุกครั้งที่ render')
})
```

### Case 2: Run ครั้งเดียว (ตอน mount)

```tsx
useEffect(() => {
  console.log('รันครั้งเดียวตอน mount')
}, []) // empty dependency array
```

### Case 3: Run เมื่อบางค่าเปลี่ยน

```tsx
const [count, setCount] = useState(0)

useEffect(() => {
  console.log('count เปลี่ยนเป็น', count)
}, [count]) // รันเมื่อ count เปลี่ยน
```

### Workshop: Update Document Title

เพิ่ม useEffect เพื่อแสดง count ใน tab title:

```tsx
import { useState, useEffect } from 'react'

function App() {
  const [count, setCount] = useState(0)

  useEffect(() => {
    document.title = `Count: ${count}`
  }, [count])

  return (
    <div>
      <h1>Counter App</h1>
      <p>ค่าปัจจุบัน: {count}</p>
      <button onClick={() => setCount(c => c + 1)}>+</button>
      <button onClick={() => setCount(c => c - 1)}>-</button>
    </div>
  )
}

export default App
```

ลองกด + ไปเรื่อยๆ → ดู tab title เปลี่ยนไหม

## 4. Cleanup Function

### ทำไมต้อง Cleanup?

บาง operation เมื่อสร้างแล้วต้องทำลายเมื่อ unmount เช่น:
- clearInterval
- removeEventListener
- cancel API request

### ตัวอย่าง: Timer

```tsx
function Timer() {
  const [seconds, setSeconds] = useState(0)

  useEffect(() => {
    const interval = setInterval(() => {
      setSeconds(s => s + 1)
    }, 1000)

    // Cleanup: ทำลาย interval เมื่อ component unmount
    return () => clearInterval(interval)
  }, []) // empty = run ครั้งเดียว

  return <p>เวลา: {seconds} วินาที</p>
}
```

## 5. useRef

### useRef คืออะไร?

`useRef` สร้าง object ที่ **เก็บค่าได้โดยไม่ทำให้ re-render**

### ใช้เก็บค่าที่เปลี่ยนแต่ไม่อยาก re-render

```tsx
const [count, setCount] = useState(0)
const countRef = useRef(0) // countRef.current = 0

function logWithoutRender() {
  countRef.current += 1
  console.log('countRef:', countRef.current) // เปลี่ยนแต่ไม่ re-render
}
```

### ใช้อ้างอิง DOM Element

```tsx
function AutoFocusInput() {
  const inputRef = useRef<HTMLInputElement>(null)

  useEffect(() => {
    inputRef.current?.focus()
  }, [])

  return <input ref={inputRef} type="text" />
}
```

### Workshop: Reset Button

เพิ่มปุ่ม reset ที่ใช้ useRef จับค่า count สูงสุด:

```tsx
import { useState, useRef } from 'react'

function App() {
  const [count, setCount] = useState(0)
  const maxRef = useRef(0)

  function increment() {
    const newCount = count + 1
    setCount(newCount)
    if (newCount > maxRef.current) {
      maxRef.current = newCount
    }
  }

  return (
    <div>
      <h1>Counter App</h1>
      <p>ค่าปัจจุบัน: {count}</p>
      <p>ค่าสูงสุด: {maxRef.current}</p>
      <button onClick={increment}>+</button>
      <button onClick={() => setCount(c => c - 1)}>-</button>
      <button onClick={() => setCount(0)}>Reset</button>
    </div>
  )
}

export default App
```

## 6. useCallback

### ปัญหา: Function สร้างใหม่ทุก render

```tsx
function Parent() {
  const [count, setCount] = useState(0)

  // ❌ สร้าง function ใหม่ทุกครั้งที่ render
  const handleClick = () => {
    console.log('clicked')
  }

  return <Child onClick={handleClick} />
}
```

เมื่อ `handleClick` สร้างใหม่ → child re-render ด้วย (ถ้า child ไม่ memo)

### วิธีแก้: useCallback

```tsx
import { useCallback } from 'react'

function Parent() {
  const [count, setCount] = useState(0)

  // ✅ function เดิมจะถูก reuse จนกว่า dependency จะเปลี่ยน
  const handleClick = useCallback(() => {
    console.log('clicked')
  }, [])

  return <Child onClick={handleClick} />
}
```

### ใช้เมื่อไหร่?

| ใช้ | ไม่ต้องใช้ |
|-----|-----------|
| Pass function เป็น prop ไป child ที่เป็น `React.memo` | Function ใช้ใน render ตรงๆ |
| Function อยู่ใน dependency ของ useEffect | Function ธรรมดาไม่มี optimization |
| ใช้ใน dependency array ของ hook อื่น | — |

:::tip อย่าใช้เกินจำเป็น
`useCallback` มี overhead สำหรับสร้าง memoized function ถ้าไม่จำเป็น ไม่ต้องใช้
:::

## 7. Custom Hooks

### ทำไมต้อง Custom Hook?

เมื่อ logic ซ้ำกันในหลาย components → สกัดออกมาเป็น hook

### Workshop: สร้าง useCounter

```tsx
// src/hooks/useCounter.ts
import { useState, useCallback } from 'react'

export function useCounter(initialValue = 0) {
  const [count, setCount] = useState(initialValue)

  const increment = useCallback(() => setCount(c => c + 1), [])
  const decrement = useCallback(() => setCount(c => c - 1), [])
  const reset = useCallback(() => setCount(initialValue), [initialValue])

  return { count, increment, decrement, reset }
}
```

### ใช้ useCounter

```tsx
// src/App.tsx
import { useCounter } from './hooks/useCounter'

function App() {
  const { count, increment, decrement, reset } = useCounter()

  return (
    <div>
      <h1>Counter App</h1>
      <p>ค่าปัจจุบัน: {count}</p>
      <button onClick={increment}>+</button>
      <button onClick={decrement}>-</button>
      <button onClick={reset}>Reset</button>
    </div>
  )
}

export default App
```

### Workshop: สร้าง useLocalStorage

สร้าง hook ที่เก็บ state ไว้ใน localStorage:

```tsx
// src/hooks/useLocalStorage.ts
import { useState, useEffect } from 'react'

export function useLocalStorage<T>(key: string, initialValue: T) {
  const [value, setValue] = useState<T>(() => {
    const stored = localStorage.getItem(key)
    return stored ? JSON.parse(stored) : initialValue
  })

  useEffect(() => {
    localStorage.setItem(key, JSON.stringify(value))
  }, [key, value])

  return [value, setValue] as const
}
```

### ใช้ useLocalStorage

```tsx
const [name, setName] = useLocalStorage('name', '')

return (
  <div>
    <input
      value={name}
      onChange={e => setName(e.target.value)}
      placeholder="ชื่อของคุณ"
    />
    <p>สวัสดี {name}!</p>
  </div>
)
```

## Recap

| Hook | ใช้ทำอะไร | Syntax |
|------|----------|--------|
| **useState** | เก็บ state ที่เปลี่ยนได้ | `const [value, setValue] = useState(initial)` |
| **useEffect** | side effects (API, subscriptions) | `useEffect(fn, [deps])` |
| **useRef** | เก็บค่าโดยไม่ re-render, ref DOM | `const ref = useRef(initial)` |
| **useCallback** | memoize function | `useCallback(fn, [deps])` |
| **Custom Hook** | สกัด logic ไปใช้ซ้ำ | `function useX() { ... }` |
