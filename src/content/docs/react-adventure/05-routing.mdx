## 1. TanStack Router Setup

### ทำไมต้อง TanStack Router?

- **Type-safe** — route params เป็น type-safe
- **Nested routes** — layout nesting ง่าย
- **Data loading** — load functions ในตัว
- **Code splitting** — auto ตาม route

### ติดตั้ง

```bash
npm install @tanstack/react-router
```

### สร้าง Router Config

สร้าง `src/router.tsx`:

```tsx
import { createRouter, createRootRoute, createRoute, Outlet } from '@tanstack/react-router'

// สร้าง root route
const rootRoute = createRootRoute({
  component: () => (
    <div>
      <Outlet />
    </div>
  )
})

// สร้าง home route
const indexRoute = createRoute({
  getParentRoute: () => rootRoute,
  path: '/',
  component: () => <div>หน้าแรก</div>
})

// สร้าง route tree
const routeTree = rootRoute.addChildren([indexRoute])

// สร้าง router
export const router = createRouter({ routeTree })

// สร้าง type สำหรับ router
declare module '@tanstack/react-router' {
  interface Register {
    router: typeof router
  }
}
```

### เพิ่ม Router ใน main.tsx

แก้ `src/main.tsx`:

```tsx
import React from 'react'
import ReactDOM from 'react-dom/client'
import { RouterProvider } from '@tanstack/react-router'
import { router } from './router'
import { ThemeProvider } from './contexts/ThemeContext'

ReactDOM.createRoot(document.getElementById('root')!).render(
  <React.StrictMode>
    <ThemeProvider>
      <RouterProvider router={router} />
    </ThemeProvider>
  </React.StrictMode>
)
```

### เพิ่ม TanStack Router Vite plugin

แก้ `vite.config.ts`:

```tsx
import { defineConfig } from 'vite'
import react from '@vitejs/plugin-react'
import tsconfigPaths from 'vite-tsconfig-paths'
import { tanstackRouterVite } from '@tanstack/react-router-vite'

export default defineConfig({
  plugins: [
    react(),
    tsconfigPaths(),
    tanstackRouterVite() // เพิ่ม plugin นี้
  ]
})
```

## 2. Type-Safe Routes

### Route แบบ Type-Safe

TanStack Router สร้าง types อัตโนมัติจาก route definitions:

```tsx
// สร้าง route พร้อม params
const productRoute = createRoute({
  getParentRoute: () => rootRoute,
  path: '/products/$productId', // $ หมายถึง dynamic param
  component: ProductDetailPage
})

// ใช้งาน — productId จะเป็น string type
function ProductDetailPage() {
  const { productId } = useParams({ from: '/products/$productId' })
  // productId: string
}
```

### Link Component

```tsx
import { Link } from '@tanstack/react-router'

// ใช้ Link แทน <a>
<Link to="/">หน้าแรก</Link>
<Link to="/products/$productId" params={{ productId: '1' }}>ดูสินค้า</Link>
```

### useNavigate

```tsx
import { useNavigate } from '@tanstack/react-router'

function MyComponent() {
  const navigate = useNavigate()

  return (
    <button onClick={() => navigate({ to: '/products' })}>
      ไปหน้า products
    </button>
  )
}
```

## 3. Layouts & Nested Routes

### สร้าง App Layout

```tsx
// src/routes/__root.tsx
import { createRootRoute, Outlet } from '@tanstack/react-router'

  component: () => <Layout><Outlet /></Layout>

```

### Nested Routes

```tsx
// src/router.tsx
import { createRouter, createRootRoute, createRoute } from '@tanstack/react-router'
import { RootRoute } from './routes/__root'
import { HomePage } from './routes/home'
import { ProductsPage } from './routes/products'
import { ProductDetailPage } from './routes/products.$productId'
import { CartPage } from './routes/cart'

const rootRoute = createRootRoute({
  component: () => <RootRoute />
})

const indexRoute = createRoute({
  getParentRoute: () => rootRoute,
  path: '/',
  component: HomePage
})

const productsRoute = createRoute({
  getParentRoute: () => rootRoute,
  path: '/products',
  component: ProductsPage
})

const productDetailRoute = createRoute({
  getParentRoute: () => rootRoute,
  path: '/products/$productId',
  component: ProductDetailPage
})

const cartRoute = createRoute({
  getParentRoute: () => rootRoute,
  path: '/cart',
  component: CartPage
})

const routeTree = rootRoute.addChildren([
  indexRoute,
  productsRoute,
  productDetailRoute,
  cartRoute
])

export const router = createRouter({ routeTree })

declare module '@tanstack/react-router' {
  interface Register {
    router: typeof router
  }
}
```

## 4. Load Functions

### ทำไมต้องมี Load Function?

Load functions ใช้สำหรับ **โหลดข้อมูลก่อน render** — เหมือน data fetching แต่เป็น route-level

### ตัวอย่าง: Product Detail Load Function

```tsx
// src/routes/products.$productId.tsx
import { createRoute, useParams, useLoaderData } from '@tanstack/react-router'
import { products } from '../../data/products'

export const ProductDetailRoute = createRoute({
  getParentRoute: () => rootRoute,
  path: '/products/$productId',
  loader: ({ params }) => {
    const product = products.find(p => p.id === params.productId)
    if (!product) {
      throw new Error('Product not found')
    }
    return { product }
  },
  component: ProductDetailPage
})

function ProductDetailPage() {
  const { product } = useLoaderData({ from: '/products/$productId' })

  return (
    <div className="max-w-2xl mx-auto">
      <span className="text-8xl block text-center mb-4">{product.image}</span>
      <h1 className="text-3xl font-bold mb-2">{product.name}</h1>
      <p className="text-gray-500 dark:text-gray-400 mb-4">{product.category}</p>
      <p className="text-2xl font-bold text-blue-600 dark:text-blue-400 mb-6">
        ฿{product.price.toLocaleString()}
      </p>
      <AddToCartButton product={product} />
    </div>
  )
}
```

### Data Loading Pattern

```tsx
// สำหรับ product list

```

### Error Handling

```tsx
const productRoute = createRoute({
  getParentRoute: () => rootRoute,
```

### Products Page

```tsx
// src/routes/products.tsx
import { createRoute } from '@tanstack/react-router'
import { useState } from 'react'
import { products, categories } from '../../data/products'
import { FilterBar } from '../../components/FilterBar'
import { ProductCard } from '../../components/ProductCard'

export const ProductsPage = createRoute({
  getParentRoute: () => rootRoute,
  path: '/products',
  component: ProductsComponent
})

function ProductsComponent() {
  const [selectedCategory, setSelectedCategory] = useState('all')

  const filteredProducts = selectedCategory === 'all'
    ? products
    : products.filter(p => p.category === selectedCategory)

  return (
    <div>
      <h1 className="text-2xl font-bold mb-6 text-gray-900 dark:text-white">
        สินค้าทั้งหมด
      </h1>
      <FilterBar
        categories={categories}
        selected={selectedCategory}
        onSelect={setSelectedCategory}
      />
      <div className="grid grid-cols-1 md:grid-cols-2 lg:grid-cols-3 gap-6">
        {filteredProducts.map((product, index) => (
          <ProductCard key={product.id} product={product} index={index} />
        ))}
      </div>
    </div>
  )
}
```

### Cart Page

```tsx
// src/routes/cart.tsx
import { createRoute } from '@tanstack/react-router'
import { Link } from '@tanstack/react-router'
import { motion } from 'framer-motion'
import { useCartStore } from '../../stores/cartStore'

export const CartPage = createRoute({
  getParentRoute: () => rootRoute,
  path: '/cart',
  component: CartComponent
})

function CartComponent() {
  const { items, removeItem, clearCart } = useCartStore()
  const totalPrice = items.reduce((sum, item) => sum + item.price * item.quantity, 0)

  return (
    <div className="max-w-3xl mx-auto">
      <h1 className="text-2xl font-bold mb-6 text-gray-900 dark:text-white">
        🛒 ตะกร้าสินค้า
      </h1>

      {items.length === 0 ? (
        <div className="text-center py-12">
          <p className="text-xl text-gray-500 dark:text-gray-400 mb-4">
            ยังไม่มีสินค้าในตะกร้า
          </p>
          <Link
            to="/products"
            className="text-blue-500 hover:underline"
          >
            ไปหน้าสินค้า
          </Link>
        </div>
      ) : (
        <div className="space-y-4">
          {items.map((item) => (
            <motion.div
              key={item.id}
              initial={{ opacity: 0, x: -20 }}
              animate={{ opacity: 1, x: 0 }}
              className="bg-white dark:bg-gray-800 rounded-xl shadow p-4 flex items-center gap-4"
            >
              <span className="text-4xl">{item.image}</span>
              <div className="flex-1">
                <h3 className="font-semibold text-gray-900 dark:text-white">
                  {item.name}
                </h3>
                <p className="text-gray-500 dark:text-gray-400">
                  ฿{item.price.toLocaleString()} x {item.quantity}
                </p>
              </div>
              <p className="font-bold text-gray-900 dark:text-white">
                ฿{(item.price * item.quantity).toLocaleString()}
              </p>
              <button
                onClick={() => removeItem(item.id)}
                className="px-3 py-1 bg-red-500 hover:bg-red-600 text-white rounded transition-colors"
              >
                ลบ
              </button>
            </motion.div>
          ))}

          <div className="bg-white dark:bg-gray-800 rounded-xl shadow p-4 flex justify-between items-center">
            <button
              onClick={clearCart}
              className="text-red-500 hover:text-red-600"
            >
              ล้างตะกร้า
            </button>
            <div className="text-right">
              <p className="text-xl font-bold text-gray-900 dark:text-white">
                รวม: ฿{totalPrice.toLocaleString()}
              </p>
              <Link
                to="/checkout"
                className="inline-block mt-2 px-6 py-2 bg-green-600 hover:bg-green-700 text-white rounded-lg transition-colors"
              >
                ชำระเงิน
              </Link>
            </div>
          </div>
        </div>
      )}
    </div>
  )
```

## 6. Route Types Reference

| Syntax | Meaning |
|--------|---------|
| `path: '/'` | Static route |
| `path: '/products/$id'` | Dynamic route param |
| `path: '/products'` | Nested route parent |
| `loader: () => {...}` | Load data before render |
| `errorComponent: () => ...` | Show on error |
| `<Link to="/path">` | Navigate |
| `useNavigate()` | Programmatic navigation |
| `useParams({ from: '/route' })` | Get URL params |
| `useLoaderData({ from: '/route' })` | Get loader data |

:::tip Type Safety
ใช้ `from` parameter ใน `useParams` และ `useLoaderData` เพื่อให้ TypeScript รู้ว่า route ไหน และ params/data มี type อะไร
:::
