## Part 4: State ของร้านชา

พอมีหลายหน้า ข้อมูลบางอย่างต้องถึงทั้งแถบบนและการ์ดโดยไม่ส่ง props ไล่ลงมาทั้งต้นไม้

ตัวอย่างที่ไม่อยากได้: หน้าเมนูรับ `items` แค่เพื่อส่งต่อให้การ์ด, แถบบนรับ `items` แค่เพื่อโชว์เลข, หน้าตะกร้าก็รับ `items` อีกที component ตรงกลางไม่ได้ใช้ข้อมูลนั้นเอง เรียกว่า props drilling

ร้านชาแยกสองที่เก็บ:

- **Context** สำหรับธีมสว่าง/มืด เพราะค่าเดียวและเปลี่ยนไม่บ่อย
- **Zustand** สำหรับตะกร้า เพราะมีการเพิ่ม จำนวน ลบ รวมราคา และต้องให้หลาย component อ่านเฉพาะส่วนที่ตัวเองใช้
