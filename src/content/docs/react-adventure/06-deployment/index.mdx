## Part 6: ขึ้น Vercel

ร้านชาเป็น SPA ไม่มีเซิร์ฟเวอร์ของตัวเอง Vercel แจกไฟล์ที่ `vite build` สร้างไว้ แล้วเขียน URL ที่ไม่ตรงไฟล์กลับไปที่ `index.html` เพื่อให้เปิด `/cart` ตรงๆ ได้

พาร์ต 7 กับ 8 เพิ่ม loader และเทสต์เข้าโปรเจกต์เดียวกัน ถ้าจะ deploy รอบเดียว ให้ทำสองพาร์ตนั้นก่อนแล้วค่อย push
