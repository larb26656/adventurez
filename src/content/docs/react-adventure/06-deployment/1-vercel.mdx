ก่อนอัปขึ้นโฮสต์ ให้รันบนเครื่องจนผ่าน:

```bash
npm test
npm run build
```

`dist/` ต้องมี `index.html` และ `products.json` ไฟล์ใน `public/` ถูกก็อปไปที่รากของ `dist`

## vercel.json

เปิด `/cart` แล้วรีเฟรช เซิร์ฟเวอร์จะหาไฟล์ชื่อ cart ไม่เจอ ถ้าไม่เขียน rewrite จะได้ 404 ทั้งที่แอปมีหน้านี้อยู่

```json
{
  "rewrites": [{ "source": "/(.*)", "destination": "/index.html" }]
}
```

Vercel เสิร์ฟไฟล์ที่มีอยู่จริงก่อน แล้วค่อยใช้ rewrite ดังนั้น `/products.json` ยังเป็น JSON ของเมนู ไม่ถูกแทนด้วย `index.html`

## ผ่าน Vercel CLI

```bash
npm install -g vercel
vercel login
cd tea-shop
vercel
```

ตอบคำถามประมาณนี้:

```text
Which scope? → บัญชีของคุณ
Link to existing project? → No
What's your project's name? → tea-shop
In which directory is your code located? → ./
Want to modify settings? → No
```

ได้ URL แนว `tea-shop.vercel.app` รอบถัดไปหลังแก้โค้ดใช้ `vercel --prod`

ใน repo ตัวอย่าง โฟลเดอร์ที่ build คือ `examples/react-tea-shop` ถ้า deploy จาก repo นี้ให้ชี้ root directory ของโปรเจกต์ Vercel ไปที่โฟลเดอร์นั้น และตั้งชื่อโปรเจกต์ว่า `tea-shop`

## ผ่าน GitHub
