## Part 5: ฟอร์มของร้านชา

มีสองฟอร์ม ทั้งคู่ไม่มี backend

- **เข้าสู่ระบบ** ตรวจอีเมลกับรหัสผ่านเป็นภาษาไทย แล้วจำอีเมลไว้ใน auth store
- **สั่งชา** รับชื่อผู้รับกับโน้ต พอผ่านแล้วโชว์ว่าจัดออเดอร์แล้ว และล้างตะกร้า

ใช้ React Hook Form 7 คู่กับ Zod 3 ผ่าน `@hookform/resolvers`

```bash
npm install react-hook-form zod @hookform/resolvers
```
