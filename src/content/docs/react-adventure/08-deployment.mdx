## บทนี้เราจะได้อะไร

- Push project ขึ้น **GitHub**
- Deploy ขึ้น **Vercel** ฟรี
- ตั้งค่า **environment variables**
- ใช้ **custom domain** (ถ้ามี)
- สร้าง portfolio จริงจาก project ที่ทำมา

---

## 1. เตรียม Project สำหรับ Production

### Build ลองดู

ก่อน deploy ลอง build ดูว่า error ไหม:

```bash
npm run build
```

ถ้า build สำเร็จจะเห็น `dist/` folder ที่มี optimized files

### ตรวจสอบ Environment Variables

ถ้า app ใช้ env variables:

```bash
# .env.example (สร้างไว้ให้คนอื่นรู้ว่าต้องตั้งอะไร)
VITE_API_URL=https://api.example.com
VITE_APP_TITLE=My Portfolio
```

สำหรับ Vercel ตั้งค่าใน dashboard ได้เลย

### ตรวจสอบ Port

Vercel ใช้ port `3000` เป็น default ถ้าใช้ Vite:

```bash
# vite.config.ts
import { defineConfig } from 'vite'

export default defineConfig({
  server: {
    port: 3000 // Vercel ต้องการ port นี้
  }
})
```

## 2. Push ขึ้น GitHub

### สร้าง Repository ใหม่

1. ไปที่ [github.com](https://github.com)
2. Click **New repository**
3. ตั้งชื่อ เช่น `my-portfolio`
4. Click **Create repository**

### Initialize Git และ Push

```bash
cd my-portfolio

git init
git add .
git commit -m "Initial commit: React portfolio app"

git branch -M main
git remote add origin https://github.com/yourusername/my-portfolio.git
git push -u origin main
```

### .gitignore

ตรวจสอบว่า `.gitignore` มี:

```
node_modules
dist
.env
.env.local
```

## 3. Deploy ขึ้น Vercel

### วิธีที่ 1: Import from GitHub (แนะนำ)

1. ไปที่ [vercel.com](https://vercel.com)
2. Login ด้วย GitHub
3. Click **Add New** → **Project**
4. Import `my-portfolio` repository
5. Vercel จะ auto-detect Vite project
6. Click **Deploy**

### วิธีที่ 2: Vercel CLI

```bash
npm install -g vercel
cd my-portfolio
vercel
```

### หลัง Deploy สำเร็จ

Vercel จะให้ URL เช่น:
```
https://my-portfolio.vercel.app
```

เปิดดูว่า app ทำงานไหม

## 4. Custom Domain (ถ้ามี)

### ตั้งค่า Domain

1. ไปที่ Project Settings → **Domains**
2. พิมพ์ domain เช่น `portfolio.dev`
3. Click **Add**
4. Vercel จะบอกว่าต้องเพิ่ม DNS records อะไร
5. ไปเพิ่ม records ที่ domain registrar

### DNS Records

```
Type    Name    Value
A       @       76.76.21.21
CNAME   www     cname.verceldns.com
```

### รอ Propagate

DNS propagate อาจใช้เวลา 5-30 นาที

## 5. CI/CD: Auto Deploy

### Auto Deploy เมื่อ Push

Vercel จะ auto-deploy ทุกครั้งที่ push ไป `main` branch

### Preview Deployments

ทุก pull request จะได้ preview URL — ดูได้ก่อน merge

### Production Branch

```bash
# ถ้าต้องการ deploy จาก branch อื่น
vercel --prod
```

### แก้ Cart → Contact

```tsx
// src/stores/contactStore.ts
import { create } from 'zustand'

interface ContactStore {
  name: string
  email: string
  message: string
  setName: (name: string) => void
  setEmail: (email: string) => void
  setMessage: (message: string) => void
  reset: () => void
}

export const useContactStore = create<ContactStore>((set) => ({
  name: '',
  email: '',
  message: '',
  setName: (name) => set({ name }),
  setEmail: (email) => set({ email }),
  setMessage: (message) => set({ message }),
  reset: () => set({ name: '', email: '', message: '' })
}))
```
