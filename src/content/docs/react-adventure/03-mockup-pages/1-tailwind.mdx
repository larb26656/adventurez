ร้านชาใช้ Tailwind CSS 4 คู่กับ `@tailwindcss/vite` ไม่ต้องมี `tailwind.config.js`, `postcss.config.js`, หรือบรรทัด `@tailwind base`

## ติดตั้ง

```bash
npm install tailwindcss @tailwindcss/vite
```

ใน `vite.config.ts` ใส่ plugin `tailwindcss()` ร่วมกับ React และ TanStack Router ไฟล์เต็มอยู่บท Router เพราะ plugin อยู่ไฟล์เดียวกัน บรรทัดที่เกี่ยวกับ Tailwind คือ:

```ts
import tailwindcss from '@tailwindcss/vite'
```

```ts
    tailwindcss(),
```

## CSS ทั้งไฟล์

```css
@import 'tailwindcss';

@custom-variant dark (&:where(.dark, .dark *));

body {
  margin: 0;
  min-height: 100vh;
}
```

`@import 'tailwindcss'` ดึง base, component, utility มาให้

`@custom-variant dark (&:where(.dark, .dark *))` ทำให้คลาส `dark:` ทำงานเมื่อ `<html>` มีคลาส `dark` ซึ่ง `ThemeProvider` เป็นคนใส่ ไม่ได้ผูกกับ media query อย่างเดียว

## คลาสที่ใช้บนการ์ด

| ความหมาย | คลาสบนร้านชา |
| --- | --- |
| พื้นการ์ด | `bg-white dark:bg-stone-900` |
| มุมโค้ง | `rounded-2xl` |
| ปุ่มส้ม | `bg-amber-800 text-white` |
| ตารางเมนู | `grid grid-cols-2 gap-6 lg:grid-cols-4` |
| จัดกลาง emoji | `flex h-36 items-center justify-center` |

ตัวอย่างปุ่มบนการ์ด:

```tsx
      <button
        type="button"
        onClick={handleAdd}
        className="mt-4 w-full rounded-lg bg-amber-800 py-2 font-semibold text-white hover:bg-amber-900"
      >
        เพิ่มลงตะกร้า
      </button>
```
