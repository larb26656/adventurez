`src/routes/cart.tsx` คือหน้า `/cart` ของไม่ได้มาจาก array ที่เขียนตายตัวในไฟล์ มันอ่าน `items` จาก `useCartStore`

แต่ละแถวโชว์ชื่อ, ราคาต่อแก้วคูณจำนวน, ปุ่มลบจำนวน, ปุ่มเพิ่มจำนวน, ปุ่มลบทั้งแถว, และราคารวมของแถวนั้นเป็นบาท

ถ้ารายการว่าง แสดงคำว่า "ตะกร้าว่าง" และไม่โชว์ปุ่มสั่งชา

รวมท้ายบิลมาจาก `getTotal()` ซึ่งคูณ `price * quantity` ทุกแถวแล้วบวกกัน ชานม 50 บาทสองแก้วกับมัทฉะ 55 บาทหนึ่งแก้ว ได้ 155

ปุ่ม "สั่งชา" เป็น `<Link to="/checkout">` ไม่ได้ตัดเงิน

<ChatMessage message="กดลบจนจำนวนเหลือ 0 แล้ว store จะตัดแถวนั้นทิ้ง ไม่ปล่อย quantity ติดลบ" avatarKey="blackCat" />

```tsx
import { createFileRoute, Link } from '@tanstack/react-router'
import { useCartStore } from '../stores/cartStore.ts'

export const Route = createFileRoute('/cart')({
  component: CartPage,
})

function CartPage() {
  const items = useCartStore((state) => state.items)
  const updateQuantity = useCartStore((state) => state.updateQuantity)
  const removeItem = useCartStore((state) => state.removeItem)
  const getTotal = useCartStore((state) => state.getTotal)
  const total = getTotal()

  return (
    <section className="mx-auto max-w-xl">
      <h1 className="mb-8 text-3xl font-bold">ตะกร้า</h1>
      {items.length === 0 ? (
        <p className="text-stone-500">ตะกร้าว่าง</p>
      ) : (
        <div className="rounded-2xl border border-stone-200 bg-white dark:border-stone-700 dark:bg-stone-900">
          {items.map((item) => (
            <div
              key={item.id}
              className="flex items-center justify-between gap-4 border-b border-stone-200 px-4 py-4 last:border-b-0 dark:border-stone-700"
            >
              <div>
                <h2 className="font-semibold">{item.name}</h2>
                <p className="text-sm text-stone-500">
                  ฿{item.price} × {item.quantity}
                </p>
                <div className="mt-2 flex items-center gap-2">
                  <button
                    type="button"
                    onClick={() => updateQuantity(item.id, item.quantity - 1)}
                    className="h-8 w-8 rounded border border-stone-300"
                    aria-label={`ลดจำนวน ${item.name}`}
                  >
                    -
                  </button>
                  <span>{item.quantity}</span>
                  <button
                    type="button"
                    onClick={() => updateQuantity(item.id, item.quantity + 1)}
                    className="h-8 w-8 rounded border border-stone-300"
                    aria-label={`เพิ่มจำนวน ${item.name}`}
                  >
                    +
                  </button>
                  <button
                    type="button"
                    onClick={() => removeItem(item.id)}
                    className="ml-2 text-sm text-red-700"
                  >
                    ลบ
                  </button>
                </div>
              </div>
              <p className="font-bold text-amber-800 dark:text-amber-300">
                ฿{item.price * item.quantity}
              </p>
            </div>
          ))}
          <div className="flex items-center justify-between bg-stone-50 px-4 py-4 dark:bg-stone-800">
            <span className="font-bold">รวม</span>
            <span className="text-2xl font-bold">฿{total}</span>
          </div>
        </div>
      )}
      {items.length > 0 && (
        <Link
          to="/checkout"
          className="mt-6 block rounded-lg bg-amber-800 py-3 text-center font-semibold text-white hover:bg-amber-900"
        >
          สั่งชา
        </Link>
      )}
    </section>
  )
}
```

รายละเอียดของ `addItem`, `updateQuantity`, `removeItem` อยู่ในบท Zustand พาร์ต 4 ไฟล์นี้คือจุดที่ UI เรียกมัน
