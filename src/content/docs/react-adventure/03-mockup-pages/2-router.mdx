React ไม่มี router ในตัว ถ้ายัดทุกหน้าไว้ใน component เดียวแล้วใช้ `useState` สลับการแสดง URL จะไม่เปลี่ยน กด back ของเบราว์เซอร์แล้วไม่ย้อนหน้า และส่งลิงก์ให้เพื่อนไม่ได้

ร้านชาใช้ TanStack Router 1 แบบไฟล์ วางไฟล์ใน `src/routes` แล้ว plugin สร้าง `src/routeTree.gen.ts` ให้ ไม่ได้ลงทะเบียน path ทีละเส้นในไฟล์แยก

## ติดตั้ง

```bash
npm install @tanstack/react-router
npm install -D @tanstack/router-plugin
```

## Vite

Plugin ของ router ต้องมาก่อน `react()` ปิด code splitting อัตโนมัติไว้ เพื่อให้ไฟล์ route ยัง export `Route` ตรงๆ อ่านในบทเรียนได้

```ts
import tailwindcss from '@tailwindcss/vite'
import { tanstackRouter } from '@tanstack/router-plugin/vite'
import react from '@vitejs/plugin-react'
import { defineConfig } from 'vitest/config'

export default defineConfig({
  plugins: [
    tanstackRouter({
      target: 'react',
      autoCodeSplitting: false,
      quoteStyle: 'single',
      semicolons: false,
    }),
    react(),
    tailwindcss(),
  ],
  test: {
    environment: 'jsdom',
    include: ['src/**/*.test.tsx'],
  },
})
```

บล็อก `test` เป็นของ Vitest ในพาร์ต 8 ใส่ไว้ไฟล์เดียวกันได้เลย

## ต่อ Router ใน main

```tsx
import { StrictMode } from 'react'
import { createRoot } from 'react-dom/client'
import { RouterProvider, createRouter } from '@tanstack/react-router'
import { ThemeProvider } from './contexts/ThemeContext.tsx'
import { routeTree } from './routeTree.gen'
import './index.css'

const router = createRouter({ routeTree })

declare module '@tanstack/react-router' {
  interface Register {
    router: typeof router
  }
}

createRoot(document.getElementById('root')!).render(
  <StrictMode>
    <ThemeProvider>
      <RouterProvider router={router} />
    </ThemeProvider>
  </StrictMode>,
)
```

`createRouter` รับ `routeTree` ที่ plugin สร้าง `declare module` ลงทะเบียน type ของ router นี้ เพื่อให้ `<Link to="...">` ตรวจ path ผิดได้ตั้งแต่ตอน typecheck

`routeTree.gen.ts` ถูกเขียนทับทุกครั้งที่รัน dev หรือ build เปิดดูได้ แต่ไม่ต้องแก้

## ไฟล์กับ path

| ไฟล์ | URL |
| --- | --- |
| `src/routes/__root.tsx` | โครงของทุกหน้า |
| `src/routes/index.tsx` | `/` เมนูชา |
| `src/routes/cart.tsx` | `/cart` |
| `src/routes/login.tsx` | `/login` |
| `src/routes/checkout.tsx` | `/checkout` |

แต่ละไฟล์ export ชื่อ `Route` จาก `createFileRoute` หรือ `createRootRoute` ลิงก์ภายในแอปใช้ `<Link to="/cart">` ไม่ใช้ `<a href>` เพื่อไม่ให้ทั้งหน้าโหลดใหม่
