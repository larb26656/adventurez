## Part 3: หน้าตาของร้านชา

จากบทนี้ไป ทุกหน้าอยู่ใน `src/routes` ของ TanStack Router แบบ file-based ชื่อไฟล์คือ path ไม่สลับหน้าด้วย `useState`

หน้าแรกคือเมนูชา ตะกร้าอยู่ที่ `/cart`

<img src="/react-adventure/mockup-home.png" alt="โครงหน้าเมนู มีปุ่ม All cold Hot และการ์ดสินค้า" />

<img src="/react-adventure/mockup-cart.png" alt="โครงหน้าตะกร้า มีรายการ ราคารวม และปุ่ม checkout" />

ปุ่มบนสเก็ตช์เขียนว่า All, cold, Hot ในแอปเป็นภาษาไทย: ทั้งหมด, เย็น, ร้อน ค่าในโค้ดยังเป็น `all`, `cold`, `hot`

สิ่งที่จะได้ทำ:

- **Tailwind CSS 4** ผ่าน Vite plugin
- **TanStack Router** สร้าง route จากไฟล์
- **Layout** แถบบนคงที่ แล้ว `<Outlet />` สลับเนื้อหา
- **เมนู, ตะกร้า, เข้าสู่ระบบ** เป็นหน้าของร้านเดียวกัน
