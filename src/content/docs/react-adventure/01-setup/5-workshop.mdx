## Workshop: สร้าง Counter App

ตอนนี้เราพร้อมสร้าง app แรกแล้ว! ค่อยๆทำตาม step ไป

### Step 1: แก้ App.tsx

แทนที่ code เดิมใน `src/App.tsx`:

```tsx
function App() {
  return (
    <div>
      <h1>Counter App</h1>
      <p>ค่าปัจจุบัน: 0</p>
      <button>+</button>
      <button>-</button>
    </div>
  )
}

export default App
```

### Step 2: Run

```bash
npm run dev
```

เปิด `http://localhost:5173` จะเห็น:
- หัวข้อ "Counter App"
- ค่า "0"
- ปุ่ม + และ -

แต่ปุ่มยังไม่ทำงาน — เพราะเรายังไม่มี state ในบทต่อไปเราจะเพิ่ม

## Recap

| หัวข้อ | สิ่งที่ได้เรียนรู้ |
|--------|------------------|
