## Props คือ arguments ของ component

แม่ส่งข้อมูลให้ลูกผ่าน attribute ของ JSX ลูกอ่านได้อย่างเดียว ไม่แก้ props ตรงๆ

การ์ดร้านชารับ `product` ทั้งก้อน ไม่รับทีละ field กระจาย เพราะรูปสินค้ามี id, ชื่อ, ราคา, emoji และอุณหภูมิ

```tsx
export function ProductCard({
  product,
}: {
  product: { name: string; price: number; temperature: 'cold' | 'hot' }
}) {
  return (
    <article>
      <h2>{product.name}</h2>
      <p>{product.temperature === 'cold' ? 'เย็น' : 'ร้อน'}</p>
      <p>฿{product.price}</p>
    </article>
  )
}
```

ค่าเริ่มต้นใส่ตอนแตก props ได้:

```tsx
export function Badge({ text = 'ใหม่' }: { text?: string }) {
  return <span>{text}</span>
}
```

## Callback

ลูกคุยกลับหาแม่ด้วยฟังก์ชันที่แม่ส่งมา ปุ่มเพิ่มลงตะกร้าในตัวอย่างฝึกทำแบบนี้:

```tsx
export function AddButton({ onAdd }: { onAdd: () => void }) {
  return (
    <button type="button" onClick={onAdd}>
      เพิ่มลงตะกร้า
    </button>
  )
}
```

ตัวอย่างฝึกส่ง `onAdd` ผ่าน props การ์ดร้านชาในพาร์ต 4 ไม่ทำแบบนี้ มันเรียก `addItem` จาก Zustand เอง เพราะตะกร้าถูกใช้ทั้งหน้าเมนู แถบบน และหน้าตะกร้า การส่ง callback ไล่จากบนลงล่างจะกลายเป็น props drilling
