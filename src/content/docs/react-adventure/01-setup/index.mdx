## Part 1: Setup & Fundamentals — พื้นฐาน React

เริ่มต้นสร้าง React project และเรียนรู้พื้นฐานที่จำเป็น — JSX, Components และ Props

สิ่งที่จะได้เรียนรู้:
- **Vite** — Development environment ที่เร็ว
- **JSX** — เขียน HTML ใน React
- **Components** — สร้าง UI ที่นำกลับมาใช้ใหม่ได้
- **Props** — ส่งข้อมูลระหว่าง Components
