## Part 1: Setup - เปิดร้านชา

บทนี้เปิดโปรเจกต์ฝึก `react-basics` แล้วปูพื้น JSX, Component, Props และ TypeScript ร้านชาเริ่มที่พาร์ต 3

สิ่งที่จะได้เรียนรู้:

- **Vite + React 19 + TypeScript 5** บน Node 22
- **JSX** เขียน UI ของการ์ดชา
- **Components** แบ่งหน้าร้านเป็นชิ้น
- **Props** ส่งเมนูเข้าการ์ด
- **TypeScript** กำหนดรูปของสินค้าชา

ตัวอย่างที่รันได้ของพาร์ตนี้: [examples/react/basics](https://github.com/larb26656/adventurez/tree/main/examples/react/basics)
