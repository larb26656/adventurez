## Component คืออะไร?

Component คือฟังก์ชันที่ return JSX รับข้อมูลเข้า (props) แล้วคืน UI

ร้านชาไม่ได้เขียนทั้งหน้าในไฟล์เดียว เราแยกอย่างน้อยเป็นแถบบน (`RootLayout`), การ์ดเมนู (`ProductCard`), ฟอร์มเข้าสู่ระบบ (`LoginForm`) และฟอร์มสั่งชา (`CheckoutForm`)

```tsx
// ตัวอย่างฝึก การ์ดจริงมีปุ่มและอ่าน store
function ProductCard() {
  return (
    <article>
      <h2>ชานมไต้หวัน</h2>
      <p>฿50</p>
    </article>
  )
}
```

เหตุผลที่แยก: ปุ่ม "เพิ่มลงตะกร้า" อยู่บนการ์ดทุกใบ แก้ข้อความหรือสีที่ component เดียว ทุกใบเปลี่ยนตาม

## กฎสามข้อ

### 1. ชื่อขึ้นต้นด้วยตัวใหญ่

```tsx
// ตัวอย่างฝึก
function ProductCard() {}
// function productCard() {}  React จะไม่มองว่าเป็น component
```

### 2. ต้อง return บางอย่าง

return JSX หรือ `null` ถ้าไม่ต้องการแสดงอะไร `null` ใช้ได้ เช่นซ่อนปุ่มสั่งชาตอนตะกร้าว่าง แต่ร้านชาเลือกแสดงข้อความ "ตะกร้าว่าง" แทน

### 3. มี parent เดียว

ถ้าต้องคืนหลายก้อนโดยไม่เพิ่ม `<div>` ให้ใช้ Fragment:

```tsx
// ตัวอย่างฝึก
function TeaHeading() {
  return (
    <>
      <h1>เมนูชา</h1>
      <p>ราคาเป็นบาท</p>
    </>
  )
}
```

## ร้านชาประกอบจาก component ยังไง

`main.tsx` ไม่ได้ render `<App />` แล้วสลับหน้าเอง มันห่อ `RouterProvider` ด้วย `ThemeProvider` แล้วแต่ละ URL ไปที่ไฟล์ใน `src/routes/`

- `/` แสดงเมนู แล้วเมนูเรียก `ProductCard` ทีละใบ
- `/cart` แสดงตะกร้า
- `/login` เรียก `LoginForm`
- `/checkout` เรียก `CheckoutForm`

บทหน้าตาเว็บจะประกอบ route พวกนี้ ส่วนบท component นี้ขอให้จำแค่ว่า UI ที่ซ้ำกันควรเป็นฟังก์ชันที่ return JSX
