## Component คืออะไร?

Component คือฟังก์ชันที่ return JSX รับข้อมูลเข้า (props) แล้วคืน UI

บทนี้แยกการ์ดออกมาเป็นฟังก์ชัน แล้วเรียกสองครั้งในหน้าเดียวกัน ร้านชาในพาร์ต 3 จะแยกต่อเป็นแถบบน, การ์ดเมนู, ฟอร์มเข้าสู่ระบบ และฟอร์มสั่งชา

```tsx
export function ProductCard() {
  return (
    <article>
      <h2>ชานมไต้หวัน</h2>
      <p>฿50</p>
    </article>
  )
}
```

เหตุผลที่แยก: ปุ่ม "เพิ่มลงตะกร้า" อยู่บนการ์ดทุกใบ แก้ข้อความหรือสีที่ component เดียว ทุกใบเปลี่ยนตาม

## กฎสามข้อ

### 1. ชื่อขึ้นต้นด้วยตัวใหญ่

`ProductCard` ด้านบนขึ้นต้นด้วยตัวใหญ่ ถ้าชื่อเป็น `productCard` React จะไม่มองว่าเป็น component

### 2. ต้อง return บางอย่าง

return JSX หรือ `null` ถ้าไม่ต้องการแสดงอะไร `null` ใช้ได้ เช่นซ่อนปุ่มสั่งชาตอนตะกร้าว่าง แต่ร้านชาเลือกแสดงข้อความ "ตะกร้าว่าง" แทน

### 3. มี parent เดียว

ถ้าต้องคืนหลายก้อนโดยไม่เพิ่ม `<div>` ให้ใช้ Fragment:

```tsx
export function TeaHeading() {
  return (
    <>
      <h1>เมนูชา</h1>
      <p>ราคาเป็นบาท</p>
    </>
  )
}
```
