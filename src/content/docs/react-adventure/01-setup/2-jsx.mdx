## JSX คืออะไร?

JSX คือ syntax ที่ให้เขียน markup คล้าย HTML ใน JavaScript มันไม่ใช่ HTML ตรงๆ TypeScript จะแปลงไฟล์ `.tsx` ให้เป็น JavaScript ที่ React เรียกใช้ได้

### JSX กับ HTML

| HTML | JSX |
| --- | --- |
| `class="card"` | `className="card"` |
| `onclick="fn()"` | `onClick={fn}` |
| `<input type="text">` | `<input type="text" />` |
| `background-color` | `backgroundColor` |

## แสดงตัวแปร

ใน JSX ใส่นิพจน์ JavaScript ด้วยปีกกา `{ }` ราคาชาเป็นตัวเลข แล้วเราเติม `฿` เอง:

```tsx
// ตัวอย่างฝึก ไม่ได้เป็นไฟล์ในร้านชา
function TeaPrice() {
  const name = 'ชานมไต้หวัน'
  const price = 50
  const cold = true

  return (
    <p>
      {name} {price} บาท ({cold ? 'เย็น' : 'ร้อน'})
    </p>
  )
}
```

บนจอจะได้ `ชานมไต้หวัน 50 บาท (เย็น)`

## เงื่อนไข

ใช้ ternary เมื่อมีสองทาง ใช้ `&&` เมื่ออยากแสดงเฉพาะตอนเงื่อนไขเป็นจริง และใช้ `return` ก่อนเมื่ออยากจบทั้ง component

```tsx
// ตัวอย่างฝึก
function ColdBadge({ cold }: { cold: boolean }) {
  return <span>{cold ? 'เย็น' : 'ร้อน'}</span>
}

function CartBadge({ count }: { count: number }) {
  return <span>{count > 0 && count}</span>
}
```

## ลิสต์

วนเมนูด้วย `.map()` ทุกตัวที่วนต้องมี `key` ที่ไม่ซ้ำ ร้านชาใช้ `product.id`

```tsx
// ตัวอย่างฝึก
const menu = [
  { id: 'milk-tea', name: 'ชานมไต้หวัน' },
  { id: 'matcha', name: 'ชาเขียวมัทฉะ' },
]

function MenuList() {
  return (
    <ul>
      {menu.map((item) => (
        <li key={item.id}>{item.name}</li>
      ))}
    </ul>
  )
}
```
