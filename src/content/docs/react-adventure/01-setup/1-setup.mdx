## ตรวจ Node 22

คอร์สนี้ใช้ Node 22 ตรวจก่อนสร้างโปรเจกต์:

```bash
node --version
npm --version
```

ต้องขึ้นต้นด้วย `v22` ถ้าเครื่องมีหลายเวอร์ชัน ให้ใช้ไฟล์ `.nvmrc` ที่มีเลข `22` ในตัวอย่างร้านชา

## สร้างโปรเจกต์

```bash
npm create vite@latest tea-shop -- --template react-ts
cd tea-shop
npm install
npm run dev
```

- `tea-shop` คือชื่อโฟลเดอร์
- `--template react-ts` คือ React + TypeScript

เปิด `http://localhost:5173` จะเจอหน้าตัวอย่างของ Vite บทถัดไปจะรื้อหน้านี้ทิ้ง แล้วค่อยๆ เปลี่ยนเป็นร้านชา

ใน repo นี้ของที่ทำเสร็จอยู่ที่ `examples/react-tea-shop` ไม่ใช่โฟลเดอร์ `tea-shop` ที่คุณสร้างเอง โครงสร้างไฟล์เหมือนกัน

## เวอร์ชันที่ล็อก

หลัง `npm create` ให้ปรับ `package.json` ให้ major ตรงกับคอร์ส แล้วรัน `npm install` ใหม่

| แพ็กเกจ | major |
| --- | --- |
| vite | 7 |
| react, react-dom | 19 |
| typescript | 5 |
| tailwindcss, @tailwindcss/vite | 4 (ติดตั้งในพาร์ต 3) |
| @tanstack/react-router, @tanstack/router-plugin | 1 (ติดตั้งในพาร์ต 3) |
| zustand | 5 (พาร์ต 4) |
| react-hook-form, @hookform/resolvers | 7 และ 3 (พาร์ต 5) |
| zod | 3 (พาร์ต 5) |

## โครงไฟล์ช่วงเริ่ม

```text
tea-shop/
├── index.html
├── package.json
├── tsconfig.json
├── tsconfig.app.json
├── tsconfig.node.json
├── vite.config.ts
└── src/
    ├── main.tsx
    └── index.css
```

| ไฟล์ | หน้าที่ |
| --- | --- |
| `index.html` | จุดเข้าของเว็บ มี `<div id="root">` |
| `src/main.tsx` | สั่ง React render ลง root |
| `vite.config.ts` | รวม plugin ของ Vite, ภายหลังจะมี Tailwind กับ TanStack Router |
| `tsconfig*.json` | ตั้งค่า TypeScript แบบที่ Vite สร้างให้ |

`index.html` ของร้านชาตั้ง `lang="th"` และชื่อแท็บเป็นร้านชา:

```html
<!doctype html>
<html lang="th">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>ร้านชา</title>
  </head>
  <body>
    <div id="root"></div>
    <script type="module" src="/src/main.tsx"></script>
  </body>
</html>
```
