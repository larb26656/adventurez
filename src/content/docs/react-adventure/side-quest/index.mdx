## Side Quests Overview

บทเรียนเหล่านี้จะพาคุณไปลึกขึ้นกว่า surface-level API เราจะมอง React จาก "ข้างใน" — ดูว่ามันทำงานยังไง และทำไมต้องเขียนแบบนี้

:::tip อ่านตอนไหน?
Side quests เหมาะกับตอนที่คุณรู้สึกว่า "เข้าใจ concept แล้ว แต่ยังสงสัยว่าทำไมต้องทำแบบนี้" หรือตอนที่อยาก debug ได้เก่งขึ้น
:::

## Available Quests

1. [React Internals](./01-react-internals) — ดูในระบบ React ว่า state ทำงานยังไง, reconciliation คืออะไร, immutable ทำไมต้องระวัง
2. [React DevTools](./02-devtools) — ใช้เครื่องมือพัฒนาตัวเลขช่วย debug performance และ component tree
