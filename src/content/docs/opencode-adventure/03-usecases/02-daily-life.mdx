### จัด Desktop

1. เปิด opencode ที่ desktop หรือ folder ที่ต้องการ

พิมพ์ prompt ต่อไปนี้
```
ช่วยจัดไฟล์ใน Desktop ให้ขอแบ่งเป็นหมวดหมู่
```

เพียงเท่านี้ AI จะจัดการจัดระเบียบไฟล์ใน Desktop ของเราให้เป็นหมวดหมู่โดยอัตโนมัติ

### สรุป meeting เป็น task
```
ช่วยสรุป meeting ดังต่อไปนี้ ออกเป็น Task หน่อยว่าต้องทำอะไรบ้าง
// ใส่ข้อความ meeting
```

AI จะทำการสกัด task จาก ข้อความ meeting ที่เราใส่ลงไป


### บันทึกรายรับรายจ่าย

1. ไปที่ repository opencode-adventure
2. เปิด opencode ที่ folder `daily-life/personal-budgeting`

พิมพ์ prompt ต่อไปนี้
```
กินข้าว 50 บาท
```

เมื่อ AI ประมวลผลเสร็จ ข้อมูลรายรับ-รายจ่ายของคุณจะถูกจัดเก็บลงไฟล์ CSV แยกตามวันให้อย่างเรียบร้อย สามารถตรวจสอบการตั้งค่ารูปแบบไฟล์เพิ่มเติมได้ที่ `daily-life/personal-budgeting/AGENTS.md`

### สร้าง report

```
ช่วยสรุปข่าว tech ที่น่าสนใจในปี 2026 พร้อมสร้าง report เป็น html ให้ผมหน่อย
```

AI จะทำการรวบรวมข่าวสารเทคโนโลยีที่น่าสนใจในปี 2026 พร้อม Export ออกมาเป็นไฟล์ HTML ที่มีรูปแบบสวยงามพร้อมใช้งานได้ทันที
