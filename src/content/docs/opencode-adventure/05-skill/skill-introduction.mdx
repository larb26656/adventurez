## Skill คืออะไร

ในโลกของ AI agent นั้นการที่จะใช้ AI ลงมือทำสิ่งต่างๆ จะต้องพึ่ง MCP หรือ tool แต่มีอีก concept หนึ่งที่สามารถให้ AI เรียนรู้ทักษะต่างๆ เพื่อลงมือทำในสิ่งที่ต้องการได้ด้วย

ยกตัวอย่าง ถ้าอยากให้ AI สร้าง slide presentation ได้ก็จะต้อง add slide presentation skill ให้กับ AI เพื่อให้ AI มีทักษะนั้น

## เปรียบเทียบกับ The Matrix

เหมือนหนัง Sci-fi เรื่อง The Matrix ในฉากที่พระเอกกำลังนั่งอยู่บนเก้าอี้ อัพโหลดทักษะ/วิชาการต่อสู้ผ่านสายเคเบิลเข้าสมองโดยตรง หลังจากนั้นเขาก็สามารถใช้วิชากังฟูได้เลย

ซึ่ง Skill ในโลก agent ก็เหมือน concept จากหนังเรื่องนี้เลย อยากให้ AI agent ทำอะไรได้ก็ใส่ skill ให้มัน

> เมื่อ AI มีทักษะครบแล้ว มันจะสามารถทำสิ่งต่างๆ ได้อย่างที่เราต้องการ!
