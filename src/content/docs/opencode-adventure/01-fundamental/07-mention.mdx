## การ mention ไฟล์

Opencode สามารถอ่านไฟล์ที่คุณต้องการได้โดยตรง โดยใช้ `@` นำหน้าชื่อไฟล์

**ตัวอย่างการใช้งาน:**

```
@src/app/page.tsx
```

## การทำงานข้ามโปรเจค

นอกจากไฟล์ในโปรเจคปัจจุบันแล้ว Opencode ยังสามารถเปิดดูไฟล์จากโปรเจคอื่นๆ ได้อีกด้วย ซึ่งจะมีข้อความขอ permission ก่อน

**ตัวอย่าง prompt ที่ reference ไฟล์จากโปรเจคอื่น:**

```
ช่วยดู pattern การเขียน authentication จาก ~/projects/my-auth-app ให้หน่อย
แล้วเอามาใช้กับโปรเจคนี้
```

## การ mention Agent

นอกจาก mention ไฟล์แล้ว คุณยังสามารถ mention Agent ที่ต้องการให้ทำเรื่องนี้ได้โดยตรง โดยใช้ `@` นำหน้าชื่อ agent

**ตัวอย่างการใช้งาน:**

```
@frontend-designer ช่วยออกแบบ UI ให้หน่อย
```
