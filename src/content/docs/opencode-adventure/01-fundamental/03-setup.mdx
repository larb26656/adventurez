## การติดตั้ง

ติดตั้งผ่าน npm:

```bash
npm i -g opencode-ai
```

**ความต้องการของระบบ:**
- Node.js 18+
- API key สำหรับ LLM ที่ต้องการใช้ (เช่น OpenAI, Anthropic, Google)

## เชื่อมต่อ Model

Opencode รองรับ LLM หลายตัว คุณสามารถเลือก model ที่เหมาะกับงานได้

**เลือก Model:**

```bash
opencode --model claude    # ใช้ Claude
opencode --model gpt       # ใช้ GPT-4
opencode --model gemini    # ใช้ Gemini
```

> แนะนำให้เริ่มต้นด้วย Claude เพราะมี context window ใหญ่และเหมาะกับงาน coding
