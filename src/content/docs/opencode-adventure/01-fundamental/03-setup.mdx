## การติดตั้ง

ติดตั้งผ่าน npm:

```bash
npm install -g opencode
```

หรือใช้ผ่าน npx โดยไม่ต้องติดตั้ง:

```bash
npx opencode
```

**ความต้องการของระบบ:**
- Node.js 18+
- API key สำหรับ LLM ที่ต้องการใช้ (เช่น OpenAI, Anthropic, Google)

## เชื่อมต่อ Model

Opencode รองรับ LLM หลายตัว คุณสามารถเลือก model ที่เหมาะกับงานได้

**วิธีตั้งค่า API Key:**

```bash
# สำหรับ OpenAI
export OPENAI_API_KEY=sk-...

# สำหรับ Anthropic (Claude)
export ANTHROPIC_API_KEY=sk-ant-...

# สำหรับ Google (Gemini)
export GOOGLE_API_KEY=...
```

**เลือก Model:**

```bash
opencode --model claude    # ใช้ Claude
opencode --model gpt       # ใช้ GPT-4
opencode --model gemini    # ใช้ Gemini
```

> แนะนำให้เริ่มต้นด้วย Claude เพราะมี context window ใหญ่และเหมาะกับงาน coding
