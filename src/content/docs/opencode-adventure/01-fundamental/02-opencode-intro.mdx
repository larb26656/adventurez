## Opencode คืออะไร

**Opencode** คือ AI Agent ที่ช่วยให้คุณทำงานด้าน Software Engineering ได้อย่างมีประสิทธิภาพ โดยทำหน้าที่เป็น "ผู้ช่วย AI" ที่สามารถ:

- อ่านและเข้าใจ codebase ของคุณ
- เขียน แก้ไข และ refactor โค้ด
- รันคำสั่งต่างๆ ใน terminal
- ค้นหาข้อมูลจากอินเทอร์เน็ต
- ทำงานร่วมกับเครื่องมือภายนอกผ่าน MCP
